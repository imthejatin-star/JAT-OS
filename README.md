# JAT OS

A personal Android-based computing environment.

Target device:
Samsung Galaxy Tab A7 Lite (SM-T225)

Target Android:
Android 14 / API 34

Architecture:
ARM64

Development:
- Termux
- Python
- HTML
- CSS
- JavaScript
- Android SDK
- Git

Project objectives:
1. Custom operating interface
2. Custom launcher
3. Android integration
4. Personal automation
5. AI assistant
6. System-level research
7. Custom Android-based OS exploration

Development principle:
Preserve original Android security and recovery options.
